## The idea

RecipeShare is a full-stack application for sharing recipes, browsing and reviewing dishes, and trading kitchen items through a peer-to-peer marketplace.

## Behind the application

- A Django backend with REST APIs and a MySQL database.
- Asynchronous filtering for browsing recipes without reloading the page.
- Session-based authentication and role-based access controls.
- Database migrations, transactional workflows, and query optimizations.

The application is packaged with Docker for a consistent development environment.
