## The idea

An automated attendance system built around face recognition, with real-time video processing and ERP integration.

## Implementation

The project combines OpenCV and ResNet-based recognition with a Raspberry Pi deployment. It connects recognition events to an ERP workflow and uses AES-encrypted storage for attendance data.
