## From code to deployment

A cloud-native delivery pipeline for a MERN application, using AWS EKS and Terraform for infrastructure provisioning and Jenkins for build, test, and deployment workflows.

## Areas of focus

- Repeatable infrastructure provisioning with Terraform.
- Multi-stage Docker builds to reduce image size.
- Automated build, test, and deployment stages.
- Centralized logging with the ELK stack to make failures easier to investigate.
